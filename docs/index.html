시장 데이터는 Yahoo Finance 및 FRED에서 가져옵니다. 가격·매크로 카드는 조회에 실패하면 ‘조회 실패’로 표시합니다. 점수 계산에 쓰는 지표(CAPE, 공포탐욕, HY 스프레드, 필라델피아 연은 지수 등)가 조회에 실패하면 중립값(예: 백분위 50)으로 대체하며, 이때는 화면 위 경고와 해당 카드에 ‘조회 실패 · 중립값 사용’ 표시가 붙습니다. 대체값으로 계산한 점수는 실제 시장 상태를 반영하지 않아요. 값 옆 날짜는 해당 데이터의 마지막 관측일입니다.
